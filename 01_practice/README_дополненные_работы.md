# Дополненные практические работы

В этом каталоге добавлены работы 01, 03, 05, 11 и 14. Для каждой работы сохранена исходная методичка как `zadanie.pdf`. В отчётах приведены решения заданий, пояснения и результаты. В SQL-практиках файлы `01_setup.sql` и `02_tasks.sql` предназначены для запуска по порядку в новой пустой базе SQLite.

- `01_Анализ_предметной_области/` — анализ шиномонтажа и ER-диаграмма.
- `03_Нормализация/` — 1НФ, 2НФ, 3НФ, BCNF и примеры декомпозиции.
- `05_Создание_таблиц/` — таблицы, ключи и ограничения.
- `11_JOIN/` — INNER, LEFT, FULL, SELF JOIN и объединение трёх таблиц.
- `14_Ограничения_и_CASE/` — CHECK, UNIQUE, DEFAULT, CASE, COALESCE и NULLIF.
