# Изменение структуры и ограничения
Внутри сохранённой папки размещены две работы из прикреплённых PDF:
- `06_Изменение_структуры/` — ALTER TABLE, пересоздание и CHECK (PDF №06).
- `08_Ссылочная_целостность/` — FK, CASCADE, RESTRICT, SET NULL, M:N (PDF №08).
Номер папки исходного архива не совпадает с названием PDF, поэтому решения разделены по темам.
