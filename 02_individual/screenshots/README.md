# Контрольные изображения

PNG-файлы сформированы автоматически по результатам выполнения SQLite-базы и SQL-запросов. Это проверяемые результаты проекта, а не снимки интерфейса DB Browser for SQLite. Если преподаватель требует именно скриншоты программы, откройте `repair_service.db` в DB Browser for SQLite и замените/дополните эти изображения собственными снимками экрана.
